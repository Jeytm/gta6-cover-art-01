An offline static web app that turns a photo + caption into GTA 6-style cover art and exports it as PNG (1080×1080, 1080×1350, 1920×1080). Six poster layouts, five colour grades, per-panel crop/position/flip. No network, no Rockstar assets.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Entry for the make.fun competition `gta6-cover-art-01`.
